# Prototypes

| Path | What it is |
|---|---|
| `climate_planet_0.5/` | The Godot 4.7 / GDScript prototype: a reduced climate model with ocean and overturning circulation, and a playable one-region game with a shadow planet. It is the gameplay fast lane and the behavioural oracle of specification §25. |
| `html/warming-stripes-v4.html` | The original browser prototype (laws, research, playtest panel). |
| `html/warming-stripes-logs-2026-09-16.json` | Two logged games from the browser prototype. |

What PlanetSim takes from the prototype — validation recipes with recorded
results, starting constants, and the shortcuts it must not copy — is
distilled in [`docs/prototype-oracle.md`](../docs/prototype-oracle.md).

Earlier versions (Godot 0.1–0.4, browser v1–v3) are in git history.
